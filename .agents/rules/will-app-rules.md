# Workspace Rules: UAE Will Preparation App

## Legal & Compliance Integrity
1. Always preserve the verbatim legal court clauses of the Abu Dhabi Civil Family Court (`ADJD-NM1221-06-01`).
2. Maintain strict bilingual two-column layout: English (LTR) on the left, Arabic (RTL) on the right.
3. Transliterate names phonetically (never translate names semantically). Always provide user review before generation.

## Visual Design Rules (The Impeccable Standard)
1. Canvas background: `#FBF9F5` (warm alabaster).
2. Deep obsidian navy: `#0B1528` (headers, hero, primary buttons).
3. Warm court bronze: `#A37E44` (stepper progress, eyebrows, CTAs).
4. Typography: Serif titles (Playfair/Cormorant), Sans body (Inter), Classical Arabic (Amiri).
5. Always reference `Reference YB WILLS/SS/` screenshots for layout, alignment, and responsiveness.

## Tech Architecture Rules
1. Next.js App Router with TypeScript (strict).
2. Neon Serverless Postgres with Prisma ORM (zero cost when idle).
3. LLM Vision API for document reading with confidence scoring and manual user confirmation.
4. CSS `@media print` engine reproducing exact court document page breaks and margins.
